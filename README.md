utworz class mysqldb która dziedziczy po klasie abstrakcyjnej database własciwosci metody oraz metody abstrakcyjne. dolacz do klasy mysqldb interfejs sql interfejs do mysqldb. abstrakcyjna klasa powinna zawierac odpowiedznie własciwosci do połączenia sie z bazą danych za pomocą funkcji mysqliconnect.

abstrakcyjna klasa database ma zawierac odpowiedznie metody do operowania na crud
1. tworzenie bazy danych
2. tworzenie tabeli
3. odczytywanie z tabeli danych
4. aktualizacja tabeli danych
5. usuwanie tabeli

   sql interfejs ma implementowac metody takie jak:
   1. findall
   2. find
   3. readone
   4. readfirtsten
